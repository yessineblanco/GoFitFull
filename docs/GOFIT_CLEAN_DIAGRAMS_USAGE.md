# GoFit Clean Diagrams - Presentation Usage

Use the SVG files below instead of the earlier generated PNG diagrams. They are cleaner, editable as vector graphics, and designed for one diagram per slide.

All final diagrams were rendered and checked as `1600 x 900` images, so they are landscape 16:9.

## Recommended Slide Order

1. Use Case Diagram

4. Class Diagram - Client Core
5. Class Diagram - Coach, AI and Admin

## How To Present Them

- Put each SVG alone on a blank 16:9 slide.
- Do not add extra text boxes around the diagram.
- Present the class diagram as two readable views, not one overcrowded diagram.
- Say clearly that the diagrams are simplified for presentation and show the main relationships only.
- For AI and BI, say they already exist in the app; the future vision is to improve and extend them.
