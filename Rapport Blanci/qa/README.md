# Report review records

Selected editorial review notes, diffs, source hashes and compiler results are versioned here. They preserve the basis and scope of the report corrections.

Raw account/device evidence from 21–24 October 2026, including screenshots, logs and provider/database readbacks, is retained locally and excluded from Git. Source snapshots, build caches and duplicate review PDFs are also excluded. Manifests may refer to excluded files; those references identify the private local archive rather than promising that every evidence file is published in this repository.

The report's selected screenshots are in `../figures/screenshots/`; the current compiled report is `../GoFit_Report.pdf`. No missing test evidence is converted to a passing result by this publication step.
