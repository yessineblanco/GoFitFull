# GoFit Cursor Plans

Cursor plans are organized by lifecycle:

- `completed/`: implemented or superseded plans retained as engineering history.
- `ongoing/`: started work with verified unresolved tasks.
- `future/`: approved work that has not started.

Move a plan rather than copying it when its lifecycle changes. Current product
priorities are summarized in `docs/ROADMAP.md`; detailed execution notes belong
in this directory.
