# GoFit Documentation Archive

This directory preserves historical GoFit documents that are no longer the
source of truth for implementation work.

- `obsolete-status/` contains status reports, task lists, and implementation
  summaries whose claims have been superseded by the current codebase.
- `academic-drafts/` contains overlapping academic drafts retained for
  traceability.

Use [the documentation index](../README.md), [the project context](../PROJECT_CONTEXT.md),
and [the live roadmap](../ROADMAP.md) for current information. Always verify
implementation claims against the code, migrations, and deployed services.
